# ElectronJS — мониторинг и управление Telegram-ботами

Десктоп-приложение для отслеживания состояния Telegram-ботов, их удалённого запуска/перезапуска и просмотра входящих сообщений в реальном времени.

## Возможности

- 📊 Отслеживание текущего состояния ботов (запущен / остановлен / ошибка)
- 🔁 Удалённый запуск и перезапуск ботов по SSH прямо из интерфейса приложения
- 💬 Просмотр сообщений, приходящих в Telegram-ботов, в реальном времени
- 🖥️ Кроссплатформенный десктоп-клиент на Electron

## Архитектура проекта

Репозиторий состоит из трёх частей:

| Папка | Назначение |
|---|---|
| `electron-app` | Десктоп-клиент (Electron) — пользовательский интерфейс для мониторинга и управления ботами |
| `SocketServer` | Сервер, обеспечивающий связь в реальном времени между ботами и клиентом (WebSocket) |
| `TelegramBots` | Код Telegram-ботов, которые отслеживаются и управляются через приложение |

Общая схема работы: **TelegramBots** отправляют события (статус, сообщения) на **SocketServer**, который транслирует их в **electron-app** в реальном времени. Команды на запуск/перезапуск ботов выполняются из **electron-app** через SSH-подключение к удалённой машине, на которой развёрнуты боты.

## Стек

- Electron
- Node.js
- WebSocket (Socket.IO / ws — уточните используемую библиотеку) — для статусов и сообщений в реальном времени
- SSH-клиент (например, `node-ssh` / `ssh2`) — для удалённого запуска и перезапуска ботов
- Telegram Bot API (уточните используемую библиотеку: node-telegram-bot-api / telegraf / grammY)

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/1mposs1blyt/ElectronJS.git
cd ElectronJS
```

Установите зависимости в каждой из трёх частей проекта:

```bash
cd SocketServer && npm install
cd ../TelegramBots && npm install
cd ../electron-app && npm install
```

## Запуск

Компоненты запускаются в следующем порядке:

1. **Socket-сервер** (должен быть запущен первым):
   ```bash
   cd SocketServer
   npm start
   ```

2. **Telegram-боты**:
   ```bash
   cd TelegramBots
   npm start
   ```

3. **Electron-приложение**:
   ```bash
   cd electron-app
   npm start
   ```

## Переменные окружения

Каждая часть проекта, вероятно, требует своих переменных окружения:

- **TelegramBots**: токены ботов
- **SocketServer**: порт/адрес для WebSocket-соединений
- **electron-app**: адрес сокет-сервера, данные для SSH-подключения (хост, порт, пользователь, путь к приватному ключу)

Создайте файл `.env` в соответствующей папке на основе `.env.example` (если присутствует). **Приватные SSH-ключи и токены никогда не коммитьте в репозиторий.**
